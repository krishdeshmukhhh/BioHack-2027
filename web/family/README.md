# Family app

Static HTML, CSS, vanilla JS, served by the hub at `/family/`. Mobile first. Accessibility rules in `.claude/rules/web.md` are acceptance criteria.

Screens (see docs/PLAN.md):

1. Today: feed progress toward the daily goal, pump state, last update time
2. Change to review: what the clinician proposed, old versus new, Confirm or Decline
3. Alert: what happened, what to do, with a picture
4. Settings: language, night mode, voice, caregiver profile
